# Return Policy

## Return Window
Most items can be returned within 30 days of the delivery date. The 30-day window starts on the day the carrier marks the order as delivered. Items delivered more than 30 days ago are not eligible for a standard return.

## Eligible Items
To be eligible for a return, an item must be in its original condition with all accessories, manuals, and packaging included. Opened electronics are accepted within the 30-day window as long as they are undamaged and all components are returned.

## Non-Returnable Items
Digital gift cards are final sale and cannot be returned or refunded. Items marked as final sale on the product page cannot be returned. Products damaged through misuse, accidents, or unauthorized repairs are not eligible for return.

## Orders That Have Not Been Delivered
An order that is still processing, shipped, or in transit cannot be returned yet. Orders that are still processing can be cancelled instead under the Cancellation Policy. Once a shipped order is delivered, the 30-day return window begins.

## How to Start a Return
Start a return from the Returns & Refunds page or by asking VSR AI Assistant in chat. You will receive a return authorization number (RMA) and a prepaid return label by email. Returns without an RMA number may be delayed or refused.

## Return Shipping
Return shipping is free for defective, damaged, or incorrect items. For all other returns, a $7.95 return shipping fee is deducted from the refund amount.
